# Cat Store Frontend

A front-end concept design for a fictional online store selling cats — built while learning HTML and CSS. Not tied to a real business; this was a self-directed project to practice building a multi-page site.

## About

This project explores what a small e-commerce-style site could look like: browsing, signing up, and basic page flow across a few connected screens. It's a front-end/design exercise, not a working application — there's no functioning backend or database behind it yet.

## Pages

- `index.html` — homepage
- `about.html` — about page
- `signup.html` — signup page
- `create.html` — create/listing page
- `messages.html` — messages page
- `updates.html` — updates page

## Tech Stack

- **HTML5** — page structure
- **CSS3** (`style.css`, `sample.css`) — styling and layout

## Status

Work in progress. `jay.py` was an early, unfinished attempt at adding backend functionality — it doesn't currently run or connect to the pages. The next steps would be learning JavaScript for client-side interactivity, then revisiting a backend once that foundation is in place.
